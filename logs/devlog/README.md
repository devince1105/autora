## 撰寫規則

- 一律使用繁體中文；程式碼、檔名、指令、任務編號（T-xxx）與事件名稱維持原文。
- 以程式碼與測試結果為準，每個結論都附上驗證方式（指令或測試名稱）。
- 與設計文件不一致之處記在這裡，並同步回 `logs/3d-office/10_TASK_BREAKDOWN.md` 的實作註記。
- 失敗與修正也要記錄，包括問題是誰造成的（例如「我寫錯的檢查順序」），不只記錄結果。
